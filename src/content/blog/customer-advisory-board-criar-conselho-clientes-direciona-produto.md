Um CAB é o grupo de 10-20 clientes top que participam ativamente do futuro do produto. Eles influenciam roadmap, validam features e se tornam advocates.

---

## Estrutura do CAB

| Aspecto | Recomendação |
|---|---|
| Tamanho | 10-20 membros |
| Perfil | Top clientes, power users |
| Frequência | Trimestral |
| Formato | Virtual + 1 presencial/ano |
| Duration | 2h por sessão |

---

## Benefícios

| Para o Produto | Para o Cliente |
|---|---|
| Feedback direto | Influência no roadmap |
| Validação de features | Acesso antecipado |
| Redução de churn | Networking VIP |
| Cases e referrals | Reconhecimento |

---

## Implementação

No [Funnels](https://usefunnels.io), membros do CAB são tagados como VIP com workflows exclusivos e comunicação personalizada.
