Viralidade em B2B existe. Não é TikTok-viral. É "meu colega me mostrou essa ferramenta e agora todo o departamento usa"-viral. O K-factor pode ser menor que em B2C, mas o LTV de cada novo user é 10x maior.

---

## Tipos de Viral Loops em B2B

| Tipo | Mecânica | Exemplo | K-Factor |
|---|---|---|---|
| Invite loop | User convida colegas | Slack, Notion | 0.3-0.7 |
| Collaboration loop | Produto exige + users | Figma, Google Docs | 0.5-1.0 |
| Content loop | User cria conteúdo público | Canva, Miro | 0.2-0.5 |
| Integration loop | Conecta com ferramentas | Zapier, Stripe | 0.1-0.3 |
| Community loop | Members indicam members | Community-led | 0.2-0.4 |
| Agency loop | Agência implementa para clientes | HubSpot, GHL | 0.5-1.5 |

---

## Métricas de Viralidade

| Métrica | Fórmula | Benchmark |
|---|---|---|
| K-factor | Invites × conversion rate | > 0.3 para B2B |
| Viral cycle time | Dias entre signup e primeiro invite | < 14 dias |
| Invite acceptance rate | Aceitos / enviados | > 30% |
| Organic signup % | Signups sem paid / total | > 40% |

---

## Como Construir

| Passo | Ação |
|---|---|
| 1 | Identifique o momento natural de compartilhamento |
| 2 | Reduza fricção do invite (1 click) |
| 3 | Dê valor para quem convida E quem é convidado |
| 4 | Meça K-factor e cycle time |
| 5 | Otimize: mais invites, melhor conversion |

## Implementação

O [Funnels](https://usefunnels.io) usa o agency loop: agências implementam o CRM para seus clientes, que por sua vez indicam para outras agências. Cada agência ativa = 10-50 sub-accounts.
