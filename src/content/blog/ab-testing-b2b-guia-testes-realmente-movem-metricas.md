---

## O que Testar (Priorizado)

| Teste | Impacto | Dificuldade |
|---|---|---|
| Pricing page | Muito alto | Médio |
| CTA text | Alto | Fácil |
| Email subject line | Alto | Fácil |
| Landing page headline | Alto | Fácil |
| Form fields | Alto | Fácil |
| Demo flow | Muito alto | Difícil |
| Onboarding | Alto | Médio |

---

## Metodologia

| Passo | Ação |
|---|---|
| 1. Hipótese | "Se mudarmos X, Y aumenta Z%" |
| 2. Sample size | Calculadora de significância |
| 3. Duração | Mínimo 2 semanas |
| 4. Single variable | Testar 1 coisa por vez |
| 5. Measure | Métrica primária + secundária |
