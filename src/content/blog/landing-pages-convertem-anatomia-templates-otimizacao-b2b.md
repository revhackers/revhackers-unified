A landing page média converte 2.35%. As top 10% convertem 11%+. A diferença não é design - é estrutura, copy e CTA.

---

## Anatomia da Landing Page Perfeita

| Seção | Objetivo | Regra |
|---|---|---|
| Hero | Capturar atenção | Value prop em 1 frase |
| Pain | Gerar identificação | 3 dores do ICP |
| Solution | Apresentar produto | Como resolve cada dor |
| Social proof | Gerar confiança | Logos + depoimentos + números |
| Features | Mostrar detalhes | 3-5 features com benefícios |
| CTA | Converter | 1 ação clara, acima da dobra |
| FAQ | Eliminar objeções | 5-7 perguntas frequentes |

## Benchmarks por Tipo

| Tipo | Conversion Rate | Uso |
|---|---|---|
| Demo request | 3-8% | High-intent |

| Webinar registro | 15-30% | Mid funnel |
| Consultation | 2-5% | Enterprise |

## Otimização (CRO)

| Teste | Impacto Típico |
|---|---|
| Headline com número | +15-25% |
| CTA acima da dobra | +20-30% |
| Remover menu | +10-20% |
| Adicionar vídeo | +10-15% |
| Social proof | +15-25% |
| Formulário curto (3 campos) | +30-50% |
