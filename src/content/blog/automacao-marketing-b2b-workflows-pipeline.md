Automação de marketing não é sobre disparar emails em massa. É sobre criar sistemas que entregam a mensagem certa, para a pessoa certa, no momento certo, sem intervenção manual.

Em B2B, onde o ciclo de vendas é longo e requer múltiplos touches, a automação é o que transforma um time de marketing de 3 pessoas em uma operação que parece ter 10.

---

## Os 10 Workflows Essenciais

### 1. Lead Capture → Welcome Sequence

| Trigger | Ação | Delay |
|---|---|---|
| Formulário preenchido | Tag "Novo Lead" | Imediato |
| | Email de boas-vindas com material | Imediato |
| | Email educacional #1 | 2 dias |
| | Email educacional #2 | 5 dias |
| | CTA para demo/consulta | 8 dias |

### 2. Content Download → Nurturing

| Trigger | Ação |
|---|---|
| Baixou ebook/guia | Tag com tema de interesse |
| | Sequence de 5 emails sobre o tema |
| | Se engajou (3+ opens) → MQL |
| | Se não engajou → lista de nurturing geral |

### 3. Blog Visit → Retargeting

| Trigger | Ação |
|---|---|
| Visitou 3+ artigos do blog | Pixel de retargeting ativado |
| | Email: conteúdo relacionado às páginas visitadas |
| | Se visitou pricing → Alert para SDR |

### 4. MQL → Sales Handoff

| Trigger | Ação |
|---|---|
| Lead Score ≥ 80 | Status muda para MQL |
| | Alerta para SDR no CRM |
| | Email ao lead: "Podemos ajudar?" |
| | Se não contatado em 4h → Escalation |

### 5. Webinar/Evento → Post-Event

| Trigger | Ação |
|---|---|
| Registrou para webinar | Sequence de lembretes (D-3, D-1, D0) |
| Participou | Email com gravação + materiais |
| Não participou | Email com gravação + CTA alternativo |
| | Follow-up em 7 dias |

### 6. Trial Signup → Activation

| Trigger | Ação |
|---|---|
| Criou conta trial | Welcome email com setup guide |
| Não completou setup em 24h | Email: "Precisa de ajuda?" |
| Completou setup | Email: próximos passos |
| Dia 7 | Case de sucesso relevante |
| Dia 12 | Oferta de call de onboarding |

### 7. Customer → Referral

| Trigger | Ação |
|---|---|
| NPS ≥ 9 | Email: pedido de review |
| | Se respondeu → pedido de referral |
| | Incentivo: desconto no próximo mês |

### 8. Lost Deal → Re-engagement

| Trigger | Ação |
|---|---|
| Deal marcado como Lost | Espera 90 dias |
| | Email: "Novidades desde nossa conversa" |
| | Se abriu → alert para SDR |
| | Repete a cada 90 dias, 3x máximo |

### 9. Upsell Detection → Expansion

| Trigger | Ação |
|---|---|
| Uso alto de feature X | Alert para CS |
| Plano perto do limite | Email: upgrade disponível |
| Contrato vence em 90 dias | Sequence de renovação |

### 10. Churn Risk → Save

| Trigger | Ação |
|---|---|
| Health Score < 50 | Alert para CS urgente |
| Login caiu 50% | Email: "Sentimos sua falta" |
| Ticket de suporte crítico | Escalation para manager |

## Implementação no CRM

No [Funnels](https://usefunnels.io), todos esses workflows são configurados visualmente no Workflow Builder, com triggers, delays, conditions e actions conectados por drag-and-drop.

| Componente | Função |
|---|---|
| Trigger | O que inicia o workflow |
| Wait/Delay | Tempo entre ações |
| If/Else | Condições de branching |
| Action | Email, SMS, WhatsApp, tag, task |
| Goal | Condição de saída |

## Conclusão

Automação de marketing B2B é a diferença entre escalar e estagnar. Enquanto marketing manual depende de memória e disciplina, automação depende de setup uma vez e execução contínua.
