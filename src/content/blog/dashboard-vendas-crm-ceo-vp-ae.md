O dashboard de vendas é onde dados se transformam em decisões. Mas a maioria dos dashboards falha por um motivo simples: tentam mostrar tudo para todo mundo.

O CEO não precisa saber quantas calls o SDR fez. O AE não precisa ver o burn rate. Cada nível da organização precisa de informações diferentes para tomar decisões diferentes.

Este artigo define exatamente quais métricas cada persona precisa ver no dashboard do CRM.

---

## O Erro: Dashboard Único para Todos

| Problema | Consequência |
|---|---|
| Dashboard com 30+ métricas | Ninguém encontra o que precisa |
| Mesma view para CEO e AE | Informação irrelevante para cada um |
| Dados desatualizados | Decisões baseadas em snapshot antigo |
| Sem drill-down | Não consegue investigar anomalias |
| Apenas métricas lagging | Vê o problema depois que aconteceu |

---

## Dashboard Layer 1: CEO / Board

O CEO precisa de uma visão de 30 segundos da saúde do negócio.

| Métrica | O que Mostra | Frequência |
|---|---|---|
| ARR atual | Tamanho do negócio | Mensal |
| MRR growth | Velocidade de crescimento | Mensal |
| NRR | Retenção líquida com expansão | Mensal |
| CAC Payback | Eficiência de aquisição | Trimestral |
| LTV:CAC | Saúde do unit economics | Trimestral |
| Burn Multiple | Eficiência do crescimento | Mensal |
| Magic Number | ROI do investimento em S&M | Trimestral |
| Cash Runway | Meses de caixa | Mensal |

Regra: o dashboard do CEO deve caber em uma tela. Se precisa scrollar, tem informação demais.

---

## Dashboard Layer 2: VP Sales / CRO

O VP Sales precisa de visibilidade sobre pipeline, forecast e performance do time.

| Métrica | O que Mostra | Frequência |
|---|---|---|
| Pipeline total por estágio | Saúde do funil | Diário |
| Pipeline coverage | Risco vs meta | Semanal |
| Forecast (commit vs best case) | Previsibilidade | Semanal |
| Win rate (rolling 90 dias) | Eficiência de conversão | Semanal |
| Avg deal size | Tamanho médio dos deals | Mensal |
| Sales cycle | Velocidade de fechamento | Mensal |
| Performance por AE | Quem está acima/abaixo da meta | Semanal |
| Deals criados vs fechados | Velocidade do pipeline | Semanal |

---

## Dashboard Layer 3: AE / Vendedor

O AE precisa saber seu status vs meta e o que fazer agora.

| Métrica | O que Mostra | Frequência |
|---|---|---|
| Revenue vs meta (mês/quarter) | Distância da meta | Diário |
| Meu pipeline por estágio | Deals que preciso trabalhar | Diário |
| Deals próximos ao fechamento | Prioridade de ação | Diário |
| Atividades da semana | Calls, emails, reuniões | Diário |
| Meu win rate | Performance pessoal | Semanal |
| Deals parados > 14 dias | Urgências de follow-up | Diário |

---

## Dashboard Layer 4: CS / Customer Success

| Métrica | O que Mostra | Frequência |
|---|---|---|
| Health Score médio do book | Saúde dos clientes | Semanal |
| Clientes em risco (Health < 60) | Prioridade de ação | Diário |
| NRR do book | Retenção + expansão | Mensal |
| Renovações próximas (90 dias) | Pipeline de renewal | Semanal |
| NPS/CSAT | Satisfação | Mensal |
| Time-to-first-value | Velocidade de onboarding | Mensal |

## Princípios de Design do Dashboard

| Princípio | Aplicação |
|---|---|
| **Uma tela, uma história** | Cada dashboard conta uma narrativa |
| **Métricas leading + lagging** | Indicadores preditivos + resultados |
| **Cores com significado** | Verde = bom, amarelo = atenção, vermelho = ação |
| **Comparação temporal** | Mostrar vs período anterior |
| **Drill-down disponível** | Click para detalhes |
| **Atualização em tempo real** | Não depender de refresh manual |

## Como Configurar no CRM

A maioria dos CRMs modernos permite criar dashboards customizados. No [Funnels](https://usefunnels.io), o dashboard é configurável por perfil de usuário, com widgets drag-and-drop que incluem:

| Widget | Dados |
|---|---|
| Pipeline funnel | Estágios, valores, quantidade |
| Revenue tracker | Meta vs realizado |
| Activity feed | Atividades recentes do time |
| Leaderboard | Ranking de vendedores |
| Forecast gauge | Commit vs best case vs pipeline |
| Health score heat map | Visão por segmento de cliente |

## Erros Comuns em Dashboards de Vendas

1. **Vanity metrics**: mostrar número de leads sem mostrar conversão é enganoso
2. **Dados de ontem**: dashboard que só atualiza uma vez por dia perde 90% do valor
3. **Sem benchmark**: mostrar "win rate 25%" sem dizer se é bom ou ruim não ajuda
4. **Sem ação clara**: cada métrica fora do normal deve ter um next step definido
5. **Dashboard = relatório**: dashboard é para monitoramento contínuo, relatório é para análise aprofundada. São coisas diferentes.

---

## Conclusão

O dashboard certo para a persona certa transforma dados em decisões. CEO vê unit economics. VP vê pipeline e forecast. AE vê sua meta e seus deals. CS vê saúde e renovações.

Configure um dashboard por persona, use cores com significado, mantenha atualizado em tempo real e tenha drill-down disponível. Isso é o mínimo para uma operação de receita data-driven.
