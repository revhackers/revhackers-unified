Ter free trial não é PLG. PLG é construir o produto como o principal canal de aquisição, ativação e expansão. Empresas PLG crescem 2x mais rápido e têm NRR 30% maior que empresas sales-led (OpenView).

---

## Os 5 Loops de PLG

### 1. Acquisition Loop

| Componente | Como Funciona |
|---|---|
| Free tier | Produto gratuito atrai users |
| Viral feature | User convida outros (ex: compartilhar projeto) |
| SEO/content | Produto gera conteúdo indexável |
| Marketplace | Users criam templates públicos |

### 2. Activation Loop

| Passo | Trigger | Ação |
|---|---|---|
| Signup | Criou conta | Welcome tour |
| Setup | Completou setup | Feature highlight |
| Aha moment | Usou feature core | Celebration + next step |
| Habit | 3+ usos | Upgrade prompt |

### 3. Monetization Loop

| Modelo | Quando Converter | Como |
|---|---|---|
| Freemium → Paid | Feature gate atingido | Modal de upgrade |
| Usage-based | Volume ultrapassou | Auto-upgrade com notificação |
| Seat-based | Equipe cresceu | Invite flow → billing |
| Hybrid | Combinação | Personalized offer |

### 4. Engagement Loop

| Trigger | Ação | Resultado |
|---|---|---|
| Inatividade | Email "Sentimos sua falta" | Re-engagement |
| Feature lançada | In-app notification | Feature adoption |
| Milestone | "Parabéns, você X!" | Satisfação |
| Feedback | NPS in-app | Insight + ação |

### 5. Expansion Loop

| Sinal | Produto Oferece | Resultado |
|---|---|---|
| Limite atingido | "Faça upgrade" com 1 click | Revenue |
| Novo use case | Cross-sell sugestão | Expansão |
| Team growth | "Convide colegas" | Seats |
