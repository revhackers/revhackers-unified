"O melhor momento para prevenir churn é no onboarding." Essa frase é repetida em todo evento de CS, mas poucos times realmente constroem um onboarding que retém. O resultado: 70% dos churns têm raiz nos primeiros 90 dias (Gainsight).

Este framework de 90 dias, baseado em milestones, não é sobre mandar emails de boas-vindas. É sobre garantir que o cliente veja valor real antes de questionar o investimento.

---

## O Framework de 90 Dias

### Fase 1: Ativação (Dias 0-14)

| Milestone | Critério de Sucesso | Responsável |
|---|---|---|
| Welcome call | Realizado em D+1 | CSM |
| Setup técnico completo | Conta configurada | CSM + produto |
| Primeiro uso real | Login + ação core | Automação |
| First Win documentado | Cliente vê valor | CSM |
| Stakeholders mapeados | Sponsor + users | CSM |

### Fase 2: Engajamento (Dias 15-45)

| Milestone | Critério de Sucesso | Responsável |
|---|---|---|
| Treinamento completo | Users treinados | CSM |
| Integração ativada | Conectou com stack | CSM + tech |
| Uso recorrente | 3+ logins/semana | Monitoramento |
| Feedback formal | NPS/CSAT coletado | Automação |
| Quick win #2 | Segundo resultado tangível | CSM |

### Fase 3: Consolidação (Dias 46-90)

| Milestone | Critério de Sucesso | Responsável |
|---|---|---|
| ROI documentado | Métricas antes vs depois | CSM |
| Adoção orgânica | Novos users sem intervenção | Monitoramento |
| Plano de expansão | Roadmap de próximos passos | CSM |
| Executive sponsor engajado | EBR agendado para D+90 | CSM |
| Handoff para CS contínuo | Transição suave | CS team |

---

## Automação do Onboarding

No [Funnels](https://usefunnels.io), configure um pipeline de onboarding com estágios que espelham as 3 fases acima. Cada milestone completado move o contato para o próximo estágio, com automações de email e alertas.

| Automação | Trigger | Ação |
|---|---|---|
| Setup incomplete | 3 dias sem setup | Email + alert CSM |
| First win achieved | Milestone atingido | Email de parabéns |
| Usage drop | Login caiu 50% | Alert CSM urgente |
| Phase complete | Todos milestones OK | Move para próximo estágio |

## Métricas de Onboarding

| Métrica | Benchmark |
|---|---|
| Time to First Value | < 7 dias |
| 14-day activation rate | > 80% |
| 90-day retention rate | > 95% |
| Onboarding NPS | > 50 |
| CSM time per onboarding | < 5 horas total |

---

## Conclusão

Onboarding que retém não é sobre checklist. É sobre garantir que o cliente veja valor real, rápido. Os 90 dias iniciais definem se o cliente fica 3 meses ou 3 anos.
